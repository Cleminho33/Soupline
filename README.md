# Soupline

L'assouplissant du gardien : une petite app web de séances de souplesse guidées, tournée vers le grand écart facial. Elle s'installe sur l'écran d'accueil d'un iPhone.

**Ouvrir l'app : https://cleminho33.github.io/Soupline/**

- Séance du soir proposée selon l'énergie du jour et le calendrier des matchs.
- Bonhomme animé, voix, rythme de respiration, mesure de l'angle par photo.
- Tout tourne dans le navigateur, sans compte ni serveur. Séances, mesures et photos restent sur le téléphone.

App personnelle, pas un avis médical : en cas de douleur qui dure, voir un professionnel de santé.
